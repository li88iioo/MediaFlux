# 进阶实战：Apple TV / Infuse / VidHub 终极 302 直连播放指南

本指南面向追求极致影音画质的家庭影院发烧友，详细介绍如何在 Apple TV 4K、iPhone、iPad 以及 Mac 平台上，利用 **Infuse Pro** 或 **VidHub** 结合 MediaFlux 实现光鸭云盘 4K HDR、杜比视界（Dolby Vision Profile 5 / 8.1）及杜比全景声（Dolby Atmos）的零损耗直连播放。

---

## 1. 为什么选择 Infuse / VidHub 直连？

| 播放链路对比 | 传统服务端实时转码推流 | MediaFlux + Infuse / VidHub 302 直连 |
| :--- | :--- | :--- |
| **画质与色彩** | 经常丢失杜比视界动态元数据、降级为 SDR 8bit | **原汁原味 10bit HDR / 杜比视界动态映射**，无任何画质压缩 |
| **音频直通** | 多声道 TrueHD / DTS-HD MA 被强制重采样为 AAC | **源码输出 / LPCM 多声道无损直通**，完美点亮回音壁/功放 |
| **服务器负载** | NAS / 服务器 CPU 占用 100%，风扇狂转 | **服务器 CPU 占用 < 1%**，仅耗时 10ms 返回 302 重定向 |
| **网络延迟** | 视频在服务器中转一次，拖动进度条卡顿 3~5 秒 | **直连光鸭 CDN 骨干网络**，拖动进度条秒开（< 500ms） |

## 3. Infuse Pro 客户端配置步骤

1. **添加 Jellyfin / Emby 媒体库**：
   - 打开 Apple TV 上的 Infuse -> `设置 -> 共享 -> 添加媒体服务器 -> Jellyfin`。
   - 输入 Jellyfin 的局域网地址（如 `http://192.168.1.100:8096`）与账号密码。
2. **播放器核心参数推荐**：
   - `流式传输模式`：设置为 **自动** 或 **直接推流 (Direct Play)**。
   - `音频输出`：设置为 **自动**（开启 Dolby Atmos 支持）。
   - `匹配内容`：在 Apple TV 系统设置中开启 `匹配动态范围 (HDR)` 与 `匹配帧率 (24Hz)`。
3. **播放测试**：
   - 进入 Infuse 海报墙，点击任意通过 STRM 挂载的 4K 电影。
   - 电视右上角将即刻点亮 **Dolby Vision** 或 **HDR** 徽标，进度条拖动丝滑秒开。

---

## 4. VidHub 客户端配置步骤

1. 打开 VidHub -> 点击右上角 `+` -> 选择 `Jellyfin / Emby`。
2. 输入服务器地址并完成登录。
3. 在 `播放设置` 中：
   - 勾选 `优先直接播放`；
   - 开启 `硬件解码加速`；
   - 缓存大小建议设为 `大 (200MB+)`，保障高码率 4K Remux 在弱网下的平稳播放。

---

## 5. 高级排错：解决 Infuse 提示“无法打开该项目”

若在 Infuse 中播放提示错误，请按以下顺序自查：
1. **`GY_STRM_BASE_URL` 是否可达**：
   - 确保 `GY_STRM_BASE_URL` 填写的是 Apple TV 和 Jellyfin 均可访问的真实 IP（例如 `http://192.168.1.100:1258`），不要填 `localhost`。
2. **反向代理 HTTPS 证书有效性**：
   - 若通过公网域名访问，确保 SSL 证书完全有效，Infuse 默认拒绝不安全的自签名证书。
