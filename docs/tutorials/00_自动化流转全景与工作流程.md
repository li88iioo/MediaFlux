# 进阶实战：MediaFlux 自动化流转全景与工作流程

MediaFlux 串联下载、识别、整理、STRM 和媒体库刷新。各阶段有独立结果：下载完成不等于整理成功，STRM 生成和后台刷新入队也不等于 Jellyfin / Emby 已扫描完成。

> 配置入口与行为核对日期：2026-11-17。先用少量文件跑通链路，再扩大自动化范围。

## 1. 全链路工作流程

```text
RSS / Telegram / Web / Agent
            │
            ▼
统一下载编排 → qBittorrent / 光鸭离线下载、分享转存
            │
            ▼
标题与季集解析 → TMDB 核验 / 成人专用来源 MetaTube
            │
            ├─ 不确定或冲突 → 待确认 → 人工选择 / 批量审阅
            ▼
本地移动 / 光鸭归档 → 操作日志与来源收尾
            │
            ├─ 本地媒体：归档路径
            └─ 光鸭媒体：STRM 变化队列 → 本地播放入口
            │
            ▼
后台合并变化路径 → Jellyfin / Emby 接受刷新请求
            │
            ▼
媒体服务器扫描与元数据处理 → 客户端可见及播放
```

## 2. 各阶段的配置与边界

### 接入与下载

- **订阅**（`/rss`）区分媒体订阅与 RSS 订阅。RSS 的启用状态、自动刷新周期和下载策略分别设置；仅订阅不会因定时抓取就自动下载。
- **设置 → 下载器**（`/settings#downloads`）维护 qB 连接与下载默认值。RSS 可继承全局目标或单独指定目标；Bot / 资源站与 RSS 保留各自的 qB 分类和路径。
- **光鸭 → 离线转存**配置云盘默认目录与分流。提交成功只表示请求被接纳，应继续看任务结果。
- **设置 → 探索设置**中的“页面显示”只控制 Web 展示，不关闭 Agent、Telegram 或订阅能力；站点选择和各业务自身的权限仍分别生效。

### 识别与人工确认

- **设置 → 刮削识别**维护 TMDB 及辅助服务；**整理规则 → 识别与命名**管理预处理、TMDB 强制匹配和命名规则。
- 文件名、原目录上下文、年份及季集信息共同参与识别；多个标题或弱匹配不会直接采用第一个搜索结果。
- 季集越界、元数据冲突或无法确定身份的内容保留待确认。在 **日志记录 → 批量审阅光鸭待确认**中，可跨页选择媒体组、保存人工候选、预览后统一确认。
- Agent 只读复核提供建议，最终确认仍受候选和季集校验约束；需先配置并启用对应 AI 功能。普通人工确认不依赖模型。

### 整理与来源清理

- **本地媒体**（`/local-media`）配置下载来源及 qB 路径前缀；归档目录统一在 **媒体库**（`/media-libraries`）维护。同盘移动与跨盘复制均会核验文件，失败回滚不等于任意中断都能无损自动恢复。
- **光鸭整理**（`/organize`）区分扫描源与归档目标。预览不移动、改名或删除云盘文件；正式任务按选定来源执行，不只处理预览展示的条数。
- **整理规则 → 分类与覆盖 → 自动回收同版本落选文件**默认开启。仅在光鸭正式执行并核实保留版本后回收落选来源及专属伴随文件；确认变空的自有下载目录可收尾至 `MF-…` 暂存根，不删除非空或受保护目录。
- 关闭该开关后保留落选文件，可在日志中手动回收。本地疑似 sample/proof 视频与未知文件另按本地规则保留，不能套用云盘清理结论。

### STRM 与播放

- **光鸭 → STRM 同步**（`/guangya/strm`）输出固定为 `STRM_ROOT/光鸭云盘/来源隔离目录/来源内相对路径`。来源数量改变不应改变其他来源已分配的目录。
- 快速同步消费持久化变化队列；完整校准遍历配置来源，核对外部改名、删除及内容变化。扫描异常或不完整时，不按缺失结果贸然清理本地镜像。
- `.strm` 保存 MediaFlux `/playgy` 入口。实际播放可能是云盘直连（302）、MF 转发或媒体服务器 HLS / 转码，取决于客户端、媒体与网络条件，不能承诺一律直连。

### 媒体库刷新与通知

- **媒体库与路径映射**把 MF 的输出目录对应到 Jellyfin / Emby 实际可见路径。两端路径相同可直接匹配，不同时需配置映射。
- 自动整理、人工确认与纠正识别共用 STRM / 刷新交接。电影尽量定位自身，剧集变化优先定位整剧以更新新集汇总日期；没有整剧条目时再退到单集、季或目录。新作品必要时扫描所属物理根或媒体库，不扩大到无关全库。
- 无法匹配或刷新失败时结束本次自动处理并记录告警，由用户在媒体服务器中手动刷新；不会无限重试旧路径。去重窗口中的新变化会延后交接。
- 通知中的“已排队”“已交接”表示 MF 的阶段结果；是否完成扫描，以媒体服务器状态和实际内容为准。
