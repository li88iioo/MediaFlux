## 1. 初始化与登录

正常启动后，全新实例在 `/setup` 填写管理员用户名、密码和确认密码；成功后在同一服务中转到 `/login`，无需重启。已有账号直接登录。已有数据库但账号配置缺失，或配置/恢复状态异常时，拒绝重新建库，请检查原有配置与备份，不要删除文件绕过检查。详见[首次安装](首次安装.md)。

![登录界面](screenshots/01_login.png)

## 2. 配置媒体服务器

在看板顶部点击“配置媒体服务器”；未配置时也可从空状态中的“去配置媒体服务”进入：

1. 选择 Jellyfin 或 Emby。
2. 填写服务地址，例如 `http://192.168.1.10:8096`。
3. 填写 API Key / Token，按需填写观看用户 ID。
4. 测试连接，启用对应节点并保存；Jellyfin 与 Emby 分别保存。

保存后的 Secret 不会回传完整明文；眼睛按钮只能显示本次输入的值，这是安全设计。

配置成功后看板显示真实媒体概览、最近播放和最近入库；未配置时显示无数据空状态。“设置 → 控制台”管理管理员凭据与登录页展示。

![看板空状态](screenshots/02_dashboard.png)

## 3. TMDB、识别与 AI 回退

进入“设置 → 刮削识别”：

- 填写 TMDB API Key 与可选 API URL。
- 选择严格匹配和刮削前确认策略。
- 可选开启 AI 结构化回退；需同时开启 Media Agent 总开关并配置模型。
- 使用“管理映射锁”查看和管理人工纠正的身份映射；映射按文件名、父目录、媒体类型和季号等上下文生效。

![刮削识别设置](screenshots/05_settings_metadata.png)

模型连接统一在“设置 → Media Agent”配置。Base URL 例如 `https://api.example.com/v1`，协议按服务商选择；“自动”使用兼容协议回退，模型列表从服务商的 `/models` 获取。主动复核是另一个独立开关：单组通过确定性校验时可自动确认，同批多组只给建议，由用户确认；不确定时仍保留人工选择。

## 4. Telegram Bot

进入“设置 → Telegram”：

1. 从 BotFather 创建 Bot 并填写 Token。
2. 填写允许操作的 Chat ID。
3. 群组或 Agent 场景填写允许用户 ID。
4. 保存后执行测试通知。

![Telegram 设置](screenshots/04_settings_telegram.png)

网络受限时，在“网络代理”配置 HTTP 代理并测试 Telegram。

## 5. qBittorrent

进入“设置 → 下载器”：

- qB Web UI 地址。
- 用户名、密码，或优先使用的 API Key。
- RSS 默认下载目标、RSS qB 分类与保存路径。
- Bot / 资源站的独立 qB 分类与保存路径。

Bot / 资源站字段未设置时继承 RSS 对应值；页面显示继承值，未编辑时仍保持继承。手动清空并保存后，分类为空表示不指定分类，路径为空表示由 qB 决定。RSS 分类继续独立保存；订阅自己的 qB 路径留空时继承 RSS 全局路径。

本地整理使用的 qB 路径前缀在“本地媒体 → 来源”配置，归档目录与媒体服务器可见路径在“媒体库与路径映射”维护。

![下载器设置](screenshots/07_settings_downloads.png)

Docker 中 qB 与 MediaFlux 的容器路径可不同，但必须指向同一宿主机目录。详见[部署指南·修改挂载路径](部署指南.md#2-修改挂载路径)。

## 6. 网络代理

进入“设置 → 网络代理”：

- 代理地址可填写 `127.0.0.1:7890`，系统会补全协议。
- 测试模式开启后，固定目标通过代理检查。
- 可分别查看 TMDB、TVDB、Telegram、GitHub、光鸭等结果。

![网络代理](screenshots/08_settings_network.png)

## 7. 光鸭登录与离线任务

进入“光鸭 → 登录”，完成短信验证。Token 支持刷新、校验和清除。

![光鸭登录与目录](screenshots/12_guangya.png)

“离线转存”配置允许扩展名和排除词。允许扩展名为空时使用内置媒体默认值；Web 输入框会展示当前有效默认项。

![光鸭离线](screenshots/13_guangya_offline.png)

## 8. 统一整理规则

进入 `/organize-rules`：

1. 确认视频扩展名和伴随文件扩展名标签。
2. 配置电影、剧集、动漫等分类目录。
3. 选择冲突、多版本和回收站策略。
4. 配置空目录清理、STRM 联动、Telegram 通知和媒体库刷新。
5. 按需增加 TMDB 强制匹配规则。

![统一整理规则](screenshots/19_organize_rules.png)

这些规则同时作用于光鸭、本地、Web、Telegram 与定时任务。输出命名与媒体规格补全采用固定契约，不提供自定义输出模板或开关：电影建立含 `{tmdb-ID}` 的独立媒体目录，剧集建立 `Season N`（如 `Season 1`，季号不补零）目录；本地文件直接使用 ffprobe，光鸭文件通过 signedURL/直链探测并缓存成功结果。探测失败回退到文件名规格，不阻断整理。

输入文件名的“发布格式”可通过 Agent 提供真实样本、只读预览，再确认保存；它只影响后续识别，不改变输出命名、TMDB 身份或季集映射。

## 9. 光鸭整理

进入 `/organize`：

- 可选择多个来源目录。
- 配置统一归档目标。
- 先生成无副作用预览，再立即整理。
- 自动任务按目录排队；需确认项目通过 Telegram 或日志详情处理。

![整理执行](screenshots/10_organize.png)

## 10. 本地媒体

部署时先挂载待整理目录和归档目录，再进入 `/local-media` 新增来源：

- 设置来源名称、qB 容器路径前缀和 MediaFlux 可见的待整理路径。
- 选择识别范围，并按需开启 qB 下载完成后的自动整理。
- 电影、剧集、动漫等归档目录与媒体服务器路径统一在 `/media-libraries` 维护，避免来源弹窗与媒体库页面双重配置。

![本地媒体](screenshots/09_local_media.png)
![新增来源](screenshots/24_local_media_modal.png)
![媒体库与路径映射](screenshots/28_media_libraries.png)

手动整理流程是“检查目录 → 识别媒体 → 预览目标 → 确认移动”。

## 11. STRM

进入“光鸭 → STRM 同步”：

- 选择一个或多个实际光鸭来源目录，不能选择根目录 ID `0`。
- `STRM_ROOT` 填 MediaFlux 可写目录。
- `GY_STRM_BASE_URL` 填媒体服务器与播放器可达的 MediaFlux 地址。
- 配置定时同步、通知和媒体库刷新。

![STRM 配置](screenshots/11_strm.png)

本地层级为 `STRM_ROOT/光鸭云盘/来源隔离目录/来源内相对路径`，不包含选中目录的父路径。已有来源沿用按目录 ID 保存的分配，同名来源会区分目录。

“快速同步”和整理联动处理变化队列；“完整校准”、`/sync_gy` 与定时任务扫描来源，用于校准外部改名、移动或删除。修改播放服务地址后，保存并执行完整校准，才能批量更新旧 STRM。后台刷新“已排队”只说明队列已接管，不能当作 Jellyfin/Emby 扫描或可播放验证完成。

Jellyfin/Emby 需要挂载同一 STRM 目录并添加媒体库。播放链路为：

```text
播放器 -> Jellyfin/Emby 读取 .strm -> MediaFlux /playgy -> 光鸭 signedURL -> 302 直连
```

## 12. RSS、下载与分享

![RSS 空状态](screenshots/15_rss.png)
![下载空状态](screenshots/16_downloads.png)
![分享转存](screenshots/14_share_transfer.png)

RSS 订阅可继承全局下载目标，也可指定 qB 或光鸭；光鸭默认目录在“离线转存”页设置，订阅中可单独选择。下载页分别记录各目标的提交和完成状态。待处理页处理下载失败或提交结果待核对的请求；后续整理、STRM 与清理问题保留在详情及日志中，无需因此重复下载。

## 13. 探索、搜索与 Agent

“设置 → 媒体探索”的“页面显示”有三个仅作用于 Web 的开关：媒体探索入口、多站资源结果、豆瓣来源。关闭后不影响 Agent、Telegram 或 RSS 的相关能力；资源站点勾选范围用于 Web、Telegram 与订阅，Agent 的公共来源范围独立，Sukebei 需单独授权。

![媒体探索设置](screenshots/06_settings_discovery.png)
![媒体探索](screenshots/29_discovery.png)
![追漫日历](screenshots/30_discovery_calendar.png)

全局搜索和最近入库通过看板顶栏进入：

![全局搜索](screenshots/21_global_search.png)
![最近入库](screenshots/20_media_recent.png)

Agent 在“设置 → Media Agent”开启总开关并配置模型。总开关默认关闭；Telegram Agent、后台巡检、AI 回退和主动复核还需各自启用。关闭父级时保留子项配置，普通 Bot 下载和网页人工操作不依赖 Agent。

普通请求通过隔离工作区调用内置 SDK。下载、转存、文件操作和配置变更等需确认的操作先展示确认卡；指定媒体库/单项刷新属于免确认能力，不能概括为所有写入都必须再次确认。模型列表与连接测试不等于业务连接、额度和工作区都已验证。

## 14. 日志与纠偏

![日志中心](screenshots/18_logs.png)

整理日志同时显示光鸭和本地来源。详情中可查看跳过原因、重新搜索 TMDB、预览目标、重新整理、回退或移入回收站。

“批量审阅光鸭待确认”按媒体组逐项选择，先预览，再确认并后台整理；原“批量纠正识别”用于把多条记录统一纠正为同一作品。详见[使用指南·批量审阅](使用指南.md#批量审阅光鸭待确认)。
