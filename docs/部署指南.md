# MediaFlux 部署指南（新手友好版）

> MediaFlux 是一个专注于轻量、高性能家庭媒体自动化流转的服务。推荐使用 **Docker Compose** 容器化部署，使用 FastAPI + uvloop + epoll 高性能异步网络栈。官方镜像默认不捆绑 ffprobe；媒体规格探测会按 `MEDIAFLUX_FFPROBE` 和系统 `PATH` 查找，缺失时降级为文件名规格，不会阻断整理。
>
> 如需进阶配置、反向代理、公网 HTTPS 或挂载调优，请参考文末的[进阶附录](#进阶附录)。

---

## 0. 我该选哪种安装方式？（30 秒决定）

| 你的情况 | 选这个 | 跳到 |
| :--- | :--- | :--- |
| **NAS（群晖/威联通/绿联/极空间/Unraid/TrueNAS）、Linux 服务器、VPS、个人电脑** | **Docker Compose（最推荐）** | [第 1 节](#1-docker-compose-一键部署推荐) |
| **开发者、想修改源码或本地调试** | **Python 源码运行** | [第 2 节](#2-python-源码运行开发者) |

> ❓ **拿不定主意？** → 直接用 **Docker Compose（第 1 节）**，环境完全隔离、性能极佳，出错也好排查。

## 1. Docker Compose 一键部署（推荐）

适合：NAS、VPS、家用服务器、个人电脑，只要安装了 Docker 即可运行。

### 1.0 先确认装好了 Docker

打开终端（NAS 可通过 SSH 连接），输入：

```bash
docker --version
docker compose version
```

- 两条命令均有版本号输出 → 继续下一步。
- 提示 "command not found" → 请先安装 Docker：
  - **群晖 (Synology)**：在套件中心安装 **Container Manager**。
  - **威联通 (QNAP)**：在 App Center 安装 **Container Station**。
  - **Ubuntu / Debian**：`curl -fsSL https://get.docker.com | sudo sh`
  - **Windows / macOS**：安装 **Docker Desktop** 或 **OrbStack**。

### 1.1 创建配置目录

```bash
mkdir -p ~/mediaflux && cd ~/mediaflux
```

### 1.2 获取项目配置文件

```bash
git clone https://github.com/li88iioo/MediaFlux.git .
cp .env.example .env
```

> 💡 若未安装 `git`：可直接前往 [GitHub 项目主页](https://github.com/li88iioo/MediaFlux) 下载 ZIP 压缩包，解压后将其中的 `docker-compose.yml` 和 `.env.example` 复制到该目录，并将 `.env.example` 复制重命名为 `.env`。

### 1.3 配置环境变量（最关键一步）

用文本编辑器打开 `.env`（如 `nano .env`），设置关键变量：

```dotenv
# ① 随机密钥：必须是一长串随机字符（至少 32 字节）
WEB_SECRET_KEY=把这里换成你生成的随机密钥

# ② 初始化标记 + 管理员账号密码（强烈建议设置高强度密码）
MEDIAFLUX_INITIALIZED=1
ENV_WEB_PASSPORT=admin
ENV_WEB_PASSWORD=换成你自己的强密码

# ③ 宿主机发布地址与端口
# 局域网访问设为 0.0.0.0；仅本机或反代访问保持 127.0.0.1
# 容器内部固定监听 0.0.0.0:1258，不需要配置容器端口变量
MEDIAFLUX_PUBLISH_HOST=127.0.0.1
WEB_PORT=1258

# ④ 镜像与存储路径
MEDIAFLUX_IMAGE=ghcr.io/li88iioo/mediaflux:latest
STRM_HOST_PATH=./strm-data
```

**如何生成随机密钥？** 任选一种方法执行：

```bash
# 方法一（Python 环境）
python3 -c "import secrets; print(secrets.token_urlsafe(48))"

# 方法二（Linux / macOS）
openssl rand -base64 48
```

### 1.4 启动服务

```bash
# 创建数据存储与媒体目录并赋予权限
mkdir -p db strm-data media-downloads media-library
sudo chown -R 10001:10001 db strm-data media-downloads media-library

# 拉取最新镜像并后台启动
docker compose pull
docker compose up -d --no-build
```

### 1.5 验证部署成功 🎉

浏览器访问：

```text
http://你的服务器IP:1258
```

- 看到登录页面 → **部署成功**。使用 `admin` 及在 `.env` 中设置的密码登录。
- 命令行健康检查：`curl http://127.0.0.1:1258/healthz`，返回 `{"status":"ok"}` 即正常。

### 😵 常见问题排查

| 现象 | 解决方法 |
| :--- | :--- |
| `docker compose` 报错 | 确认 Docker Compose 插件已安装，旧版本使用 `docker-compose` 命令 |
| 启动后打不开网页 | 查看容器日志：`docker compose logs -f mediaflux`；检查防火墙/安全组是否放行了 `1258` 端口 |
| 提示端口被占用 | 修改 `.env` 中的 `WEB_PORT`（例如改为 `1259`），再执行 `docker compose up -d` |
| 局域网设备无法访问 | 将 `.env` 中的 `MEDIAFLUX_PUBLISH_HOST` 设为 `0.0.0.0`，然后执行 `docker compose up -d` 重启 |

## 2. Python 源码运行（开发者）

适合：需要修改源码、调试功能或定制二次开发的场景。要求 **Python 3.13+**。

```bash
# 1. 创建虚拟环境并安装依赖
python3 -m venv .venv
source .venv/bin/activate        # Windows 下使用：.venv\Scripts\activate
pip install -r requirements.txt

# 2. 启动服务
python mediaflux.py start
```

启动后打开浏览器访问 `http://127.0.0.1:1258/setup`，按照向导完成初始化配置。

> ⚠️ MediaFlux 内部集成了定时调度与异步任务流转，**请保持单进程运行**，不要通过多进程 worker 启动。

<summary><b>A. 运行目录与持久化规范</b></summary>

MediaFlux 严格隔离只读应用代码与持久化数据：

| 部署方式 | 数据库文件 | 配置文件 (`user.env`) | 缓存目录 | 日志目录 | STRM 输出目录 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **Docker 容器** | `/app/db/mediaflux.db` (映射 `./db`) | `/app/db/user.env` (映射 `./db`) | `/app/db/cache` | `/app/db/logs` | `/data/strm` (映射 `${STRM_HOST_PATH}`) |
| **Python 源码** | `<repo>/db/mediaflux.db` | `<repo>/db/user.env` | `<repo>/db/cache` | `<repo>/db/logs` | `<repo>/strm-data` |

<details>
<summary><b>B. Docker 挂载本地下载目录与媒体库（本地整理）</b></summary>

主 `docker-compose.yml` 已预置挂载，只需在 `.env` 中指定宿主机路径：

```dotenv
# 待整理下载目录（宿主机真实路径）
MEDIA_DOWNLOADS_HOST_PATH=/srv/mediaflux/downloads
# 整理后的正式媒体库（宿主机真实路径）
MEDIA_LIBRARY_HOST_PATH=/srv/mediaflux/library
# 容器内允许浏览的根目录
LOCAL_MEDIA_BROWSE_ROOTS=/media/downloads,/media/library
```

Compose 自动完成映射：`宿主机路径 → /media/downloads` 与 `/media/library`。

**Web 页面填写的为容器内路径**：
- 本地来源根目录：`/media/downloads/completed`
- 电影归档目标：`/media/library/Movies`
- 剧集归档目标：`/media/library/TV Shows`
- 动漫归档目标：`/media/library/Anime`

**目录权限配置（容器以 UID/GID `10001:10001` 运行）**：
```bash
sudo setfacl -R -m u:10001:rwX /srv/mediaflux/downloads /srv/mediaflux/library
sudo setfacl -R -d -m u:10001:rwX /srv/mediaflux/downloads /srv/mediaflux/library
sudo chown -R 10001:10001 ./db ./strm-data
```

</details>

<details>
<summary><b>C. 反向代理 + HTTPS 公网访问（Nginx 示例）</b></summary>

公网环境下建议通过 Nginx 进行反向代理并开启 SSL：

```nginx
server {
    listen 80;
    server_name mediaflux.yourdomain.com;
    return 301 https://$host$request_uri;
}

server {
    listen 443 ssl http2;
    server_name mediaflux.yourdomain.com;
    ssl_certificate     /etc/letsencrypt/live/mediaflux.yourdomain.com/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/mediaflux.yourdomain.com/privkey.pem;
    client_max_body_size 100M;

    location / {
        proxy_pass http://127.0.0.1:1258;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;

        # WebSocket 支持
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";

        # 关键：关闭缓冲，保证 SSE 实时日志与 302 鉴权即时响应
        proxy_buffering off;
        proxy_cache off;
        proxy_read_timeout 3600s;
    }
}
```

</details>

<details>
<summary><b>E. STRM 目录共享与媒体播放</b></summary>

**STRM 共享**：MediaFlux 与 Jellyfin/Emby 挂载同一个宿主机 STRM 目录：

```yaml
# MediaFlux 容器
- /srv/mediaflux/strm-data:/data/strm

# Jellyfin / Emby 容器（只读挂载即可）
- /srv/mediaflux/strm-data:/media/strm:ro
```

在 MediaFlux Web 设置中：
- `STRM 根目录`：`/data/strm`
- `播放直链 Base URL`：`http://192.168.1.20:1258`（填播放器和媒体服务器能访问到的 MediaFlux 实际地址，不要填 localhost）。

</details>

<details>
<summary><b>F. 源码部署使用 systemd 托管</b></summary>

若使用 Linux 源码部署并需要开机自启与守护托管：

```ini
[Unit]
Description=MediaFlux Service
After=network-online.target

[Service]
Type=simple
User=mediaflux
WorkingDirectory=/opt/mediaflux
Environment=APP_ENV=production
Environment=WEB_HOST=0.0.0.0
Environment=WEB_PORT=1258
ExecStart=/opt/mediaflux/.venv/bin/python /opt/mediaflux/mediaflux.py start
Restart=on-failure
RestartSec=5
TimeoutStopSec=30
UMask=0027

[Install]
WantedBy=multi-user.target
```

</details>
