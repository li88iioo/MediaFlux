# MediaFlux 项目安装与配置指南
---

## 一、Docker Compose 安装与部署

> 详细说明亦可移步参考 [部署指南.md](部署指南.md)。

### 1.1 部署示例

```yaml
services:
  mediaflux:
    image: "ghcr.io/li88iioo/mediaflux:latest"
    container_name: mediaflux
    restart: unless-stopped
    environment:
      TZ: Asia/Shanghai
    stop_grace_period: 60s

    # Agent 代码工作区使用容器内 Bubblewrap 隔离，需要允许创建命名空间
    # 不需要 Agent 功能时可将下方 security_opt 移除
    security_opt:
      - seccomp=unconfined
      - apparmor=unconfined
    network_mode: host

    volumes:
      - "./mediaflux-data:/app/db"
      - "./STRM:/data/strm"
      - "/vol3/1000/下载:/media/downloads"
      - "/vol2/1000/视频:/media/library"
```

### 1.2 挂载路径说明

| 路径配置 | 说明 | 备注 |
| :--- | :--- | :--- |
| `"./mediaflux-data:/app/db"` | 数据存储路径 | 必选 |
| `"./STRM:/data/strm"` | STRM 文件存储路径 | 必选 |
| `"/vol3/1000/下载:/media/downloads"` | qBittorrent 下载路径 | 可选，不使用可不配置 |
| `"/vol2/1000/视频:/media/library"` | 本地媒体库路径 | 可选，不使用可不配置 |

## 二、光鸭配置

### 2.1 光鸭离线目录配置
- **默认保存目录**：配置一个在光鸭 App/Web 端已新建或保持一致的目录（如：`离线`）。Telegram Bot 或 RSS 未指定下载目录时，收到磁力后会自动下载到该目录。
- **最小文件体积**：建议调大或维持默认值，以减少垃圾文件入库；排除词、允许视频扩展名同理。

### 2.2 光鸭整理配置
整理入库需依次配置以下内容：

- **扫描源目录**：配置你的云盘源目录（如：`动漫`、`剧集`、`电影`）。
- **归档目标目录**：配置你的云盘归档目录（如：`整理`）。
- **整理操作**：外部获取的磁力离线或转存保存至扫描目录后，可通过发送 Telegram 命令 `/organize` 或点击 Web 页面的 **立即启动整理**，统一整理入库至光鸭云盘的 `整理` 目录。
- **目录结构与命名规则**：
  - **电影**：`分类/片名 (年份) {tmdb-ID}/片名.年份.规格.ext`
  - **剧集**：`分类/剧名 (年份) {tmdb-ID}/Season N/剧名.年份.SxxExx-规格.ext`（季目录不补零，如 `Season 1`）
  - **特别篇 (Specials)**：目录为 `Specials`，文件命名格式为 `S00E..`

### 2.3 光鸭 STRM 同步配置
- **光鸭源目录**：选择上一步设置的归档目标目录（如 `整理`）。整理入库后自动生成 STRM 要求这里包含归档目标目录本身；如果只选择其中的子目录（如 `整理/电影`），可以通过完整校准或定时扫描单独同步这些子目录，但整理完成后不会自动生成，会提示“STRM 整理联动配置错误：整理目标未唯一匹配已配置 STRM 来源”。
- **媒体反代播放服务地址**：支持自动探测或手动填写（MediaFlux 的 `IP:端口`，例如 `192.168.0.1:1258`）。
  > ⚠️ **注意**：请勿配置回环地址（如 `127.0.0.1`），否则会导致 Jellyfin 无法播放 STRM。
- **STRM 本地根目录**：对应 Docker 挂载路径中的宿主机目标路径。例如 Docker `volumes` 配置为 `- "./STRM:/data/strm"` 时，此处选择 `/data/strm` 即可。生成的 STRM 文件将保存在对应的宿主机目录中（如 `/docker/MediaFlux/STRM/光鸭云盘/整理`）。
- **小文件过滤阈值**：保持默认即可，也可根据需要增减，小于该体积的文件将跳过生成（设为 `0` 表示不限制）。
- **格式过滤与伴随元数据**：通常保持默认即可，或根据个人常用视频格式自行添加。
- **同步伴随元数据开关 & 元数据扩展名**：开启后，配置的元数据扩展名文件会自动下载至媒体所在目录（如 `.nfo`、字幕、封面）。建议若开启**仅保留字幕即可**，NFO 和封面无需同步。
- **执行 STRM 生成与同步**：点击“自动调度与运行”标签页中的 **完整校准**，或在 Telegram 中发送命令 `/sync_gy`。
- **启用定时扫描**：建议**保持关闭**（整理入库流程会自动触发生成 STRM），除非有特殊需求。

### 2.4 媒体反代配置
> 前提条件：需先完成前两步配置。

1. 配置媒体库服务器。
2. **创建反代实例**：
   - 选择配置好的媒体服务器，名称任意。
   - 监听地址推荐填写 `0.0.0.0`，端口保持默认或按需更改。
   - 若需要 Jellyfin 显示播放客户端的真实 IP：MediaFlux 默认会把实际连接的客户端 IP 转发给 Jellyfin，只需在 Jellyfin **控制台 → 网络 → 已知代理** 中填写 Jellyfin 看到的 MediaFlux 地址（host 网络模式下即 MediaFlux 宿主机 IP）。
   - 仅当 MediaFlux 前面还有 Nginx、Caddy、FRP 等反代时，才需要在反代实例的 **真实客户端 IP → 可信代理来源** 中填写这些反代的直连地址；不要填写整个局域网网段，否则局域网内任何人都能伪造客户端 IP。详见[客户端 IP 与 Jellyfin “Known Proxies”](tutorials/01_Jellyfin与Emby媒体库及STRM播放实战.md#7-客户端-ip-与-jellyfin-known-proxies)。

## 三、项目基础配置

### 3.1 Telegram Bot
- **Bot Token**：从 [@BotFather](https://t.me/BotFather) 获取。
- **通知 Chat ID**：从 [@userinfobot](https://t.me/userinfobot) 获取。
- **受信任用户白名单**：个人使用请直接填入自己的 `Chat ID`。
- **主动通知**：保持默认即可。

### 3.2 Media Agent
- 按需开启。开启后可辅助刮削识别，但整体增益有限。

### 3.3 刮削识别
- **TMDB API Key**：前往 [themoviedb.org](https://www.themoviedb.org/) 注册申请。
- **TMDB 候选召回模式**：推荐选择 **严格模式**。

## 四、整理规则配置

### 4.1 识别与命名
- **基础配置**：保持默认配置即可。
- **NSFW 内容识别**：
  - 需配合 MetaTube 服务使用（请自行搜索搭建）。
  - **归档分类目录**：名称自定，会在光鸭归档目录（如 `整理`）下创建，例如设为 `NSFW`。
  - **光鸭专用来源目录**：选择存放 NSFW 内容的目录。配置后可在 Web 界面手动识别，自动整理入库时也可将普通媒体与 NSFW 媒体区分存放。

### 4.2 分类与覆盖
- 推荐保持默认，或按个人习惯自定义分类名称。

### 4.3 同步入库
- **下游服务联动**：推荐保持默认，即保持两个开关处于**开启**状态。若不需要自动刷新媒体库或希望手动同步 STRM，可关闭此项。

## 五、媒体库映射

> 该配置主要用于更精准地进行入库与局部刷新，非必配项。

- **配置方式**：
  在配置好媒体服务器的前提下，点击添加映射，在下拉菜单中选择媒体库。
- **配置示例**：
  - 媒体库：`电视剧`
  - 来源目录：选择剧集对应的 STRM 路径，例如 `/data/strm/光鸭云盘/整理/剧集`
  - 服务器路径：即 Jellyfin 看到的目录，通常自动生成无需修改。
    > 💡 **特殊边界情况**：若将 `/data/strm/光鸭云盘/整理/综艺` 同样合并到了“电视剧”媒体库中，需在此手动修正对应的 Jellyfin 映射目录。

## 六、Jellyfin 联动与媒体删除插件

针对不喜欢的媒体，可通过 Jellyfin 客户端直接同步删除云盘源文件。

### 6.1 在线安装插件
1. 进入 **Jellyfin 管理后台** → **插件** → **存储库/仓库** → **添加**。
2. 名称填写：`MediaFlux`
3. 存储库地址填写：
   ```text
   https://github.com/li88iioo/MediaFlux/releases/download/manifest/manifest.json
   ```
4. 进入“目录”找到 MediaFlux 插件并安装，安装完成后**重启 Jellyfin 服务**。

### 6.2 插件配置
1. 打开 Jellyfin 插件设置，填写 MediaFlux 的访问地址（URL）、用户名及密码，点击 **保存配置**。
2. 点击 **同步 MF 范围**（同步使用已保存的连接信息）。
3. 确认范围无误后，勾选 **启用联动删除**，再次点击 **保存配置**。
4. 配置完成后，在 Jellyfin 界面直接删除媒体即可联动删除云盘中的对应文件。

### 6.3 STRM 起播加速
- **功能说明**：推荐开启。已播放过的 STRM 再次播放时，起播前的等待可从 1–3 秒降到几十毫秒；新入库的剧集会在后台预探测，首次播放也会加快。
- **开启方式**：在插件设置中勾选 **启用 STRM 起播加速** 并保存，无需 MediaFlux 连接。安装或更新插件后需重启 Jellyfin。

## 七、日志记录与纠错

- 在系统 **日志记录** 详情中，可以查看媒体的完整识别结果与详细整理日志。
- 若存在错误识别的媒体项目，可在日志详情中直接进行**重新识别与修正**。
