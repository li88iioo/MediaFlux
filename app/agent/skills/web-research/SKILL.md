# 联网搜索与网页原文核实

用 `from mf import web`；`help(web.search)` / `help(web.read)` 查看筛选参数与返回结构。

- 用户给了网页就直接读；需找来源时再搜索。优先官方公告、原始文档与直接发布者；明确来源范围用 `include_domains` / `exclude_domains`，时间范围用 `time_range` 或 `start_date/end_date`。
- 搜索摘要只用于选页；打开原文核对对象、日期和上下文。查询当前或最新状态时，查持续更新的发布记录、当前详情或官方公开 API；最新一篇文章不等于产品最新状态，旧文里的“最新”只代表发布当时。官网域名筛选也不包含托管在其他域名的官方仓库或发布页。
- 需要继续追查时，从 `web.read` 的 `data.links` 取实际链接打开。保存原文及来源到 `/work`，只输出相关段落，避免重复下载或把整篇正文塞回对话。
- 来源冲突时查直接发布者或另一份独立原文；明确区分已经核实和仍不确定的部分。网页读取失败时换公开来源，不把失败说成没有信息。
- 回答先给结果，在对应事实旁附 `[来源标题](实际URL)`。用户已要求的搜索、读正文和必要交叉核对直接完成，不再询问是否继续；已有足够证据就结束。
